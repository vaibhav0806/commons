# Commons design archive

The running product is the Next.js application. The current visual and interaction authority is [`../DESIGN.md`](../DESIGN.md); the implementation guide is [`../docs/DESIGN_SYSTEM.md`](../docs/DESIGN_SYSTEM.md).

The static studies, prototypes, screenshots, and local simulation flows in this directory are historical reference only. They may describe Graphite + Reflective, Space Grotesk/Geist, requests, a visual Explorer, collections, or unimplemented provider behavior. None of those descriptions authorize application changes.

Two assets remain live dependencies:

- `commons.system.css`, the shared token foundation imported by the app;
- the local font and asset files it references.

If a historical study is useful for research, reconcile the idea with the current product and design authorities before reusing it. Do not start a static server or treat old localhost routes as product QA unless the task is explicitly about archival research.
