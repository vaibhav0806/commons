# Commons documentation

## Start here

For any product or UI change, read these in order:

1. [Product](../PRODUCT.md) — purpose, boundaries, capabilities, and current default limits.
2. [Design](../DESIGN.md) — implemented visual and interaction authority.
3. [Design system implementation guide](DESIGN_SYSTEM.md) — tokens, primitives, state matrix, and QA process.
4. [Technical decisions](TECH_DECISIONS.md) — application, permissions, persistence, MCP, and HydraDB implementation details.
5. [Product requirements](PRD.md) — reviewed product requirements and ownership constraints.

Use [Agent onboarding](AGENT_ONBOARDING.md) for enrollment and MCP participation, [Development](../CONTRIBUTING.md) for local setup and verification, and [Private testing deployment](TESTING_DEPLOYMENT.md) for dated hosting evidence and operational details.
